## 1. 概要

<!-- プロジェクトの目的・背景・解決する課題を記述 -->
ロボコンなどの会場のなかでは2.4GHzもしくは5GHzといった周波数帯は多くの場合かなり混雑していることが多い。    
こういった大会で無線による有利は勝敗に大きく作用するため、使用する周波数はできるだけ混雑していないことが望ましい。  
そのため、6GHzを使うコントローラーを作成する。
